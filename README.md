# Teaching Resources – IT & Computer Science  
## University of Mumbai

This repository contains subject-wise teaching resources prepared for undergraduate programs under the University of Mumbai.

The materials are designed for academic teaching, practical sessions, assignments, and project guidance in Information Technology and Computer Science.

## 📘 Courses & Subjects Covered

### S.Y.B.Sc. Computer Science
- Mobile Application Development (MAD – Android)
- Introduction to Artificial Intelligence

### T.Y.B.Sc. Computer Science
- Information Retrieval
  
### T.Y.B.Sc. Information Technology
- IT Infrastructure Management

### Game Programming
- Practicals (1–8)
- Project Resources

## 📂 Repository Structure

Each subject folder may include:
- Practical programs
- Source code (Python / Kotlin / XML / etc.)
- Notes and documentation
- Assignments
- Project materials

Subjects are organized semester-wise and course-wise for clarity.
