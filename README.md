# Teaching Resources – IT & Computer Science  
## University of Mumbai

This repository contains structured teaching resources prepared for undergraduate programs under the University of Mumbai.

The materials are designed to support academic teaching, laboratory sessions, assignments, and project guidance in Computer Science and Information Technology.

---

## 📘 Courses & Subjects Covered

### S.Y.B.Sc. Computer Science
- Mobile Application Development (MAD – Android)
- Introduction to Artificial Intelligence

### T.Y.B.Sc. Computer Science
- Information Retrieval
- Game Programming (Practicals)

### T.Y.B.Sc. Information Technology
- IT Infrastructure Management

---

## 📂 Repository Structure

Each subject directory may include:

- Practical programs
- Source code (Python / Kotlin / XML / etc.)
- Lab manuals
- Notes and documentation
- Assignments
- Project materials

Content is organized course-wise and updated semester-wise as required.
